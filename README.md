# 箱ダイヤ描画ソフト（鉄道車両仕業行路図作成システム / β版）

ブラウザ上だけで鉄道の**車両運用表（仕業行路図・箱ダイヤ）**を表形式で作成・編集し、そのまま**1:1 ベクターPDF**として綺麗に出力できる無料のWebアプリケーションです。  
サーバー通信やインストールは不要で、GitHub Pages やローカル PC（`index.html` を直接開くだけ）で動作します。

---

## 主な特徴

- **直感的な2ペインGUI編集**: 左側の表形式エディタで入力すると、右側の図面プレビュー（SVG）がリアルタイム更新されます。
- **図面上の双方向操作**:
  - プレビュー上の列車線をクリックすると、左側の「列車表」の該当行へジャンプします。
  - 注記テキストは図面上で直接ドラッグ移動でき、**`Alt` キーを押しながらドラッグ**すると列車線（上側／下側）や駅境界（左端・中央・右端揃え）に自動吸着します。
- **高いカスタマイズ性**:
  - 路線内の駅表示オン／オフ（X座標の自動再計算）、駅名・略称・順序の自由編集に対応。
  - 列車種別ごとの色（ダイヤ線・時刻・列車番号）と線種（実線・破線・点線）を自由設定・パレット切替可能。
  - 併結表記の自動生成・連結位置選択（`後(自+相)` / `前(相+自)` / `⚙` 3両以上編成順序設定）・相手運用への着発情報リアルタイム／一括同期、部分継走（`0`行〜`1`行・`✂` 途中駅分割）、運用表示番号の自動追従、発着記号（`○` / `●` / `△` / `▲`）に対応。
- **印刷・ベクターPDF出力**: A4 / B5（縦・横）に対応し、ブラウザの印刷機能から拡大縮小ズレのない高精度なベクターPDFを生成できます。
- **JSON 保存・読み込み**: 作成したダイヤデータは JSON ファイルとしてローカル保存し、いつでも再編集できます。
- **サンプルプリセット内蔵**: 起動時に架空の鉄道データ（桜川電鉄 本線 フル体験版 / 特急・回送・試運転 / 緑川鉄道 支線コンパクト版）を収録。既存の `version: "2.0"` JSONファイルもそのまま読み込めます。

## 使い方（クイックスタート）

### 1. ブラウザで開く
- **Web版（GitHub Pages）**:  
  [https://sekitan66325.github.io/box-diagram/](https://sekitan66325.github.io/box-diagram/) にアクセスするだけですぐに使えます。
- **公開元サイト（真岡鐵道 情報ポータル）**:  
  [https://sekitan66325.github.io/](https://sekitan66325.github.io/)
- **ローカルPCで使う場合**:  
  リポジトリをダウンロードまたは `git clone` し、`index.html` を Google Chrome / Microsoft Edge / Firefox などのブラウザで直接開いてください。

### 2. 基本の操作手順
1. 画面上部のプリセットプルダウンからサンプルを選ぶか、`読込 (JSON)` で既存データを読み込みます（最初から新規編集も可能）。
2. 左側のタブ（`列車表` / `運用一覧` / `種別マスタ` / `駅マスタ` / `注記` / `基本設定`）で表を編集します。
3. 右側のプレビューで確認し、必要に応じて注記をドラッグ（`Alt` 押下で線・駅に吸着）して位置を整えます。
4. `保存 (JSON)` で作業データを手元に保存し、`印刷 / PDF出力` から PDF 保存・印刷を行います。

画面右上の **`？ 使い方`** ボタン（または `F1` キー）から、アプリ内でもいつでもヘルプを確認できます。  
不具合の報告・ご要望・ご質問は、画面右上の **`✉ お問い合わせ`** ボタンからアプリ内フォーム（または別タブ）で送信できます。  
各タブの詳細仕様や印刷設定のコツは **[取扱説明書・仕様書 (MANUAL.md)](./MANUAL.md)** をご覧ください。

## データの取り扱いについて

本アプリケーションは **100% クライアントサイド（お使いのブラウザ内のみ）** で動作します。  
入力したダイヤデータや読み込んだ JSON ファイルが外部サーバーへ送信されることはありません。編集データを残す場合は必ず上部の **`保存 (JSON)`** でダウンロードしてください。
