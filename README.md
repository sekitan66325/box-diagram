# 箱ダイヤ描画システム（箱ダイヤ描画ソフト / v1.1β）

ブラウザ上だけで鉄道の**車両運用表（仕業行路図・箱ダイヤ・時刻軸運用線図）**を表形式で作成・編集し、そのまま**1:1 ベクターPDF**として綺麗に出力できる無料のWebアプリケーションです。  
サーバー通信やインストールは不要で、GitHub Pages やローカル PC（`index.html` を直接開くだけ）で動作します。スマートフォン・タブレットからの閲覧・簡易操作にも対応しています。

---

## 主な特徴（v1.1β）

- **直感的な2ペインGUI編集＋軽量モーション**: 左側の表形式エディタで入力すると、右側の図面プレビュー（SVG）がリアルタイム更新されます。モバイル幅（900px以下）では「図面プレビュー / データ編集」の切替表示にも対応しています。
- **ゼロからの新規作成・統合ファイル読込**:
  - **`新規作成`** ボタンから路線名・運用数・用紙・駅リストを指定して白紙から作成できます。
  - **`読込 (JSON/.oud/.oud2)`** から JSON データおよび OuDia / OuDiaSecond（`.oud` / `.oud2`）を自動判別で取り込めます。
- **駅軸・時刻軸の両対応**:
  - **駅軸（箱ダイヤ）**: 左→右／右→左の上り・下り方向切替、折り返し垂直線色設定（後列車色・前列車色・黒）、省略駅名行、部分継走・途中駅分割に対応。
  - **時刻軸（運用線図 / 棒ダイヤ）**: 時間帯幅に応じた**変形用紙サイズ自動フィット（AUTO）**、日界設定、深夜目盛り表記、待機折り返し点線に対応。
- **豊富な書式・デザインカスタマイズ**:
  - タイトル・著作権表示・左上「運用番号」列見出しの編集、**ページ番号の表示有無・1ページ時非表示・7種の表記パターン・4か所の表示位置**を選択可能。
  - タイトル・駅名・運用番号・列車番号・時刻・併結・注記個別のフォント指定、時刻フォーマット（`H:MM` / `HH:MM` / `HHMM`）、線幅倍率・発着記号倍率・駅基準線/時刻罫線スタイル・運用ゼブラ背景を設定可能。
- **図面上の双方向操作**:
  - プレビュー上でマウスホイール拡大縮小・余白ドラッグパンができ、列車線をクリックすると左側の該当行へジャンプ＆強調表示します。
  - 注記テキストは図面上で直接ドラッグ移動でき、**`Alt` キーを押しながらドラッグ**すると列車線や駅境界／時刻目盛りに自動吸着します。
- **印刷・ベクターPDF出力 & JSON 保存**: `A3`〜`B6`（縦・横）・`AUTO`・任意 `CUSTOM` mm 指定に対応し、拡大縮小ズレのない高精度ベクター PDF を生成できます（`version: "2.0"` JSON 互換）。

## 使い方（クイックスタート）

### 1. ブラウザで開く
- **Web版（GitHub Pages）**:  
  [https://sekitan66325.github.io/box-diagram/](https://sekitan66325.github.io/box-diagram/) にアクセスするだけですぐに使えます。
- **公開元サイト（真岡鐵道 情報ポータル）**:  
  [https://sekitan66325.github.io/](https://sekitan66325.github.io/)
- **ローカルPCで使う場合**:  
  リポジトリをダウンロードまたは `git clone` し、`index.html` を Google Chrome / Microsoft Edge / Firefox などのブラウザで直接開いてください。

### 2. 基本の操作手順
1. 画面上部の **`新規作成`** から白紙路線を始めるか、サンプルプリセット／**`読込 (JSON/.oud/.oud2)`** から既存データを読み込みます。
2. 左側のタブ（`列車表` / `運用一覧` / `種別マスタ` / `駅マスタ` / `注記` / `基本設定`）で表やデザインを編集します。
3. 右側のプレビューで確認し、必要に応じて注記をドラッグ（`Alt` 押下で線・駅・時刻に吸着）して位置を整えます。
4. **`保存 (JSON)`** で作業データを手元に保存し、**`印刷 / PDF出力`** から PDF 保存・印刷を行います。

画面右上の **`使い方`** ボタン（または `F1` キー）からアプリ内ヘルプ、**`利用規約`** ボタンから規約・クレジット表記ルールを確認できます。  
不具合の報告・ご要望・ご質問は **`お問い合わせ`** ボタンから送信できます。各タブの詳細仕様や印刷設定のコツは **[取扱説明書・仕様書 (MANUAL.md)](./MANUAL.md)** をご覧ください。
