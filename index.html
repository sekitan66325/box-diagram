箱ダイヤ描画システム ご利用ガイド・仕様

鉄道車両仕業行路図（箱ダイヤ）の作成・編集・PDF出力をブラウザだけで完結できるツールです。

1. はじめに（基本の使い方）

1
サンプルを選ぶ・データを開く

上部のプルダウンからサンプルデータ（モオカ14形 / DE10 / C1266+50系客車）を選ぶか、読込 (JSON) から保存済みデータを読み込みます。

2
左側パネルの表で編集する

「列車表」「運用一覧」「種別マスタ」「駅マスタ」「注記」「基本設定」タブを切り替えて編集します。変更は即座に右側プレビューへ反映されます。

3
右側の図面上で確認・微調整する

図面上の列車線をクリックすると左側の該当列車行へジャンプします。注記テキストは図面上で直接ドラッグ移動できます。

4
保存・PDF出力する

作業途中のデータは 保存 (JSON) でファイル保存し、仕上げは 印刷 / PDF出力 からベクターPDFとして保存・印刷できます。

データの安全性について： すべての処理はお使いのブラウザ内だけで実行され、入力データが外部サーバーへ送信・保存されることはありません。作業後は必要に応じて 保存 (JSON) で手元に保存してください。

2. 左パネル（編集エリア）各タブの機能

タブ名 主な機能とポイント
列車表 運用を選択し、列車番号・種別・発駅/発時刻・着駅/着時刻・併結・発着記号・行高さステップ(行) を表形式で編集します。＋ 継走列車追加 を使うと直前リストの到着駅・到着+10分の時刻を引き継いで追加できます。併結欄では他運用との自動併結、⇄ での順序反転、✎ での自由記述が可能です。前列車と発着駅がつながらない行や時刻書式（H:MM）誤りは背景色で知らせます。
運用一覧 運用（A1、A2…）の追加・複製・並び替え・削除や、手動改ページモード用の「改ページ」チェックを設定します。編集 ✏️ でその運用の列車表へ直接切り替わります。
種別マスタ 普通・回送・SL・快速などの列車種別ごとに、ダイヤ線色・時刻色・列車番号色（カラーピッカー／HEX入力）・線種（実線／破線／点線）を自由に追加・設定できます。🎨 パレット読込 から標準・JR東日本風・モノクロ印刷用へ一括切替も可能です。
駅マスタ 路線内の駅一覧を管理します。「表示」チェックを切り替えると図面上に縦基準線を引き、駅間のX座標を自動再配置します。真岡鐵道の主要3駅リセット／全17駅展開ボタンや、自由な駅追加・並び替えに対応しています。
注記 図面上に置く自由テキスト（運休注記など）のページ・文言・色・文字サイズ・X/Y座標を管理します。
基本設定 図面タイトル・著作権表記、用紙サイズ（A4 / B5）と向き（縦 / 横）、自動／手動改ページ、駅名ヘッダーの向き（縦書き／横書き）、省略駅名行の表示規則、自運用番号の強調スタイル、行高・余白の微調整が行えます。
生JSON 上級者向けのJSON直接表示・コピー・編集タブです。直接編集する場合はチェックボックスをONにして 適用する を押してください（構造検証付き）。

発着記号の意味

  • 発記（出発駅側の記号）：○ 出区（白丸）／● 黒丸／ー なし
  • 着記（到着駅側の記号）：△ 入区（白三角）／▲ 終結（黒三角）／ー なし

3. 図面上の操作と「Alt吸着」機能

  • 列車線クリック連動：プレビュー上の列車線をクリックすると、左側の「列車表」で該当運用・該当列車へ自動スクロール＆ハイライトされます。
  • スプリッター幅調整：画面中央の境界線を左右にドラッグすると、編集パネルとプレビューの比率を変えられます。
  • 注記テキストの自由移動：図面上の赤い文字等の注記は、そのままマウスでドラッグして位置を調整できます（小数点0.16px単位）。
  • Alt + ドラッグで列車線に自動吸着：
    • 上側／下側スナップ：ドラッグ中に Alt キーを押すと、近くの列車線の上側または下側の基準位置へ自動吸着します（青緑の補助ガイド線が表示されます）。
    • 左端／中央／右端揃えスナップ：線の左端や各駅の基準線だけでなく、駅線手前（真岡・茂木など）への右端揃えや線区間の中央揃えにも吸着します。
    • ドラッグ中の Alt 解除：Alt キーを先に離してもその吸着位置を起点に飛び跳ねず滑らかに微調整できます（そのままマウスを離せば吸着位置に確定します）。

4. 印刷 / PDF出力とデータ保存のコツ

きれいなベクターPDFを出す印刷設定

上部の 印刷 / PDF出力（または Ctrl+P）を押すと印刷ダイアログが開きます。ブラウザ側で以下を設定すると、1:1のベクターPDFとして最も綺麗に仕上がります。

  • 送信先：PDFに保存（またはお使いのプリンタ）
  • 用紙サイズ：基本設定で選んだサイズ（A4 / B5）と一致させる
  • 余白：なし
  • 倍率：既定（または 100%）
  • オプション：背景のグラフィック にチェック推奨

データの保存と読み込み

  • 保存 (JSON) を押すと、現在編集中の全設定・全運用・注記を含む JSON ファイルがダウンロードされます。
  • 次回作業時は 読込 (JSON) からそのファイルを選択するだけで状態を復元できます。
  • ブラウザを閉じると編集内容は保持されないため、こまめな JSON 保存をおすすめします。

5. キーボードショートカット & システム仕様

ショートカット一覧

Ctrl + Z元に戻す（最大50回）
Ctrl + Y / Ctrl+Shift+Zやり直し
Ctrl + P全ページ展開して印刷 / PDF出力
Alt + 注記ドラッグ列車線（上下）・駅境界（左/中央/右端）へ吸着
F1 / Escヘルプ画面を開く / 閉じる

システム技術仕様（概要）

  • 動作形式：HTML / CSS / JavaScript + SVG（外部ライブラリ・バックエンド不要）
  • 推奨環境：Google Chrome / Microsoft Edge / Firefox 等の最新モダンブラウザ（PC画面推奨）
  • 内部座標系：SVG viewBox 1122.56 × 1587.36（0.16px グリッド基準・ベクター出力）
  • 対応用紙：A4（縦・横）/ B5（縦・横）
  • データ形式：JSON（スキーマ version: "2.0"）
